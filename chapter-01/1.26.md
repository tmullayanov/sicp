# expmod with double call instead of square

The version from the book.

```scheme
(define (expmod base exp m)
    (cond ((= 0 base) 1)
          ((even? exp)
           (remainder (* (expmod base (/ exp 2) m)
                         (expmod base (/ exp 2) m))))
          (else (* base (expmod base (- exp 1) m)))))
```


The book asks us to explain Eve's statement that the current version takes $\Theta(n)$ time instead of $\Theta(\log n)$


## Explanation


To analyze the asymptotic time complexity of divide-and-conquer algorithms, we can apply the $Master Theorem$, which addresses recurrence relations of the form:

$$
\begin{equation}
    T(n) = aT\left(\frac{n}{b}\right) + f(n),
\end{equation}
$$
where $a \geq 1$ and $b > 1$.
The asymptotic bound for $T(n)$ is determined by comparing $f(n)$ with $n^{\log_b a}$.

For the original $expmod$ procedure, the running time is governed by the following recurrence relation:
$$
\begin{equation}
    T(n) = T\left(\frac{n}{2}\right) + \Theta(1).
\end{equation}
$$

Here, $a = 1$, $b = 2$, and $f(n) = \Theta(1)$. 
Since $f(n) = \Theta(n^{\log_2 1}) = \Theta(n^0) = \Theta(1)$, this falls under Case 2 of the Master Theorem. Consequently, we obtain the solution:
$$
\begin{equation}
    T(n) = \Theta(\log n).
\end{equation}
$$

In alternative implemenation, due to the fact that `expmod` is called twice when the power gets halved, the recurrence takes slightly different form:

$$
\begin{aligned}
    T(n) = 2T\left(\frac{n}{2}\right) + \Theta(1)
\end{aligned}
$$

Here, $a = 2$, $b = 2$, $f(n) = \Theta(1)$.
The critical function $n^{\log_b a} = n^{\log_2 2} = n^1 = n$

The recursion hre is lift-heavy, it falls under Case 1 of the Master Theorem.
Consequently, we obtain the solution:

$$
\begin{aligned}
T(n) = \Theta(n)
\end{aligned}
$$
