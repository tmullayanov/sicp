# Apply function to itself

```scheme
(define (f g)
 (g 2))

(f square) ; -> 4
(f (lambda (z) (* z (+ z 1)))) ; -> 6
```

Q: What happens if we try to evaluate `(f f)`?

## Answer

To answer this, we can analyze how exactly the function is going to be applied to it's argument:

```scheme
(f f) ; each line represents the next step in the process of evaluation
((lambda (g) (g 2)) f)
(f 2)
(lambda (z) (z 2) 2)
(2 2)
error: 2 is not a function.
```

The interpreter would try to use term `2` as a function which is going to result in an error.
