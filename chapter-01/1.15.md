# Sine of x

To compute the sine of angle, we can repeatedly reduce the argument using the identity:

$$ \sin x = 3 \sin \dfrac{x}{3} - 4 \sin^3 \dfrac{x}{3} $$


For sufficiently small $x$, we may use $\sin x \approx x$.
The approximation is used when $|x| \leq 0.1 radians.$

In Scheme, this procedure can be implemented as follows:

```scheme
(define (cube x) (* x x x))

(define (p x) (- (* 3 x) (* 4 (cube x))))

(define (sine angle)
  (if (not (> (abs angle) 0.1))
    angle
    (p (sine (/ angle 3.0)))))
```

## Questions

### 1. How many times is `p` called when we evaluate `(sine 12.15)`?

```scheme
(sine 12.15)
(p (sine 4.05))
(p (p (sine 1.35)))
(p (p (p (sine 0.45))))
(p (p (p (p (sine 0.15)))))
(p (p (p (p (p (sine 0.05))))))
```

-> 5 times.
Which could be calculated as following:

$$N = \lceil \log_3 12.15 - \log_3 0.1 \rceil$$


### 2. Calculate time and space complexity for the process generated by `sine` when evaulating it as `(sine a)`.

The procedure above generates a linear recursive process.

Each application of p must remain pending until the recursive evaluation reaches the base case.
Pending applicatons are evaluated as the recursion unwinds.


The number of recursive calls of `sine` is $\Theta(\log_3 |a|) = \Theta(\log |a|)$.

Since each pending application requires to be stored until the recursive evaluation reaches the base case, the space complexity is also $\Theta(\log |a|)$
